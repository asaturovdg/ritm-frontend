# Родной рИТм: перенос согласованного дизайна

> Исполнение: superpowers:executing-plans, последовательно в этой сессии.

Цель: перенести выбранный вариант профиля и редактора, включая современный ввод контакта, в существующее сообщество. Согласованный эскиз: ritm-native.html в папке визуализаций чата. Новые цвета, зависимости и backend-маршруты не добавляются. U+00B7 не используется.

- [x] Контакт: чистые функции нормализации HTTPS без credentials, определения Telegram/MAX/сайта и краткого отображения. Тесты до реализации: username, полная ссылка, query/hash, неверная схема, credentials, восстановление существующего контакта.
- [x] ContactField: выбор типа, отдельные значения, вставка ссылок, доступное адаптивное поле и превью. В API сохраняется один contact_url и необязательная подпись. Невалидный ввод блокирует сохранение, изменение контакта сбрасывает согласие.
- [x] Профиль и редактор: общий заголовок, аватар с fallback, статус, группы «О вас», «Интересы», «Связь», действия видимости под раскрытием, разные стили основных/вторичных кнопок. Старые сценарии draft/submit/409/401 сохраняются.
- [x] Публикации: вкладки, карточки с названиями событий из существующего /events/by-ids, аватары авторов, аккуратные пустые состояния и скрытая пагинация для одной страницы. Ошибка метаданных не скрывает опубликованный текст.
- [x] Событие и модерация: переиспользовать новые элементы, формы события под раскрытием, человекочитаемый снимок профиля вместо списка служебных полей, технические ID под раскрытием.
- [x] Проверки: профильный и полный Vitest, build, ESLint изменённого модуля, browser QA с фикстурой реальных компонентов на 360/390 px и тёмной теме. Не занимать 5173. Удалить временную фикстуру, создать PR из новой ветки.

Области ревью: сохранность URL/query, состояние несохранённой формы при смене типа контакта, отсутствие автопереноса контактов аккаунта, доступ после выхода, независимость компании и календаря, запрет интервалов чтения скрытого рассказа.
